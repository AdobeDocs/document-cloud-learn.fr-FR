# Modification de documents et de modèles avant l’envoi

Les modifications de dernière minute font partie de chaque workflow. Dans ce tutoriel, découvrez comment mettre à jour le contenu du document, remplacer des images et apporter des corrections au modèle directement dans Acrobat Sign. Tous les détails sur les fonctionnalités et les limitations sont disponibles [ici](https://helpx.adobe.com/sign/web/authoring/edit-agreement/new.html).

>[!NOTE]
>
>L&#39;édition de documents doit être activée par votre administrateur. Pour plus d&#39;informations, cliquez [ici](https://helpx.adobe.com/sign/web/settings-configuration/send-settings/edit-agreement.html).
